Neon Palms is an original top-down open-world crime game set in the fictional neon coastal city of Palmera Bay, playable offline in a desktop browser from static files. Roam the city on foot or steal a car, outrun a five-star police wanted system, run a three-mission story chain for the fixer Marisol, work repeatable taxi fares, respray at the Gloss Garage, and save your progress — with traffic, pedestrians, combat, a HUD and a live minimap, all drawn in code with no external assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or just open game/index.html from the repository in the browser — everything it loads lives under game/.
